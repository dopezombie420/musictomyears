# Music to my Ears!

This mod ports the 1.7+ music system to legacy versions of Minecraft! It is written for Ornithe/Legacy Fabric.



### Configuration

##### overrideMusic

boolean: can be set to true or false.

##### survivalDelay

array: defines the minimum delay and the random additional delay.

* Example: 500-200, the minimum ticks is 200 and the random delay is 500.

##### creativeDelay

array: defines the minimum delay and the random additional delay.

* Example: 500-200, the minimum ticks is 200 and the random delay is 500.

##### netherDelay

array: defines the minimum delay and the random additional delay.

* Example: 500-200, the minimum ticks is 200 and the random delay is 500.

##### endDelay

array: defines the minimum delay and the random additional delay.

* Example: 500-200, the minimum ticks is 200 and the random delay is 500.

##### menuDelay

array: defines the minimum delay and the random additional delay.

* Example: 500-200, the minimum ticks is 200 and the random delay is 500.
